## Brain

Before you act, read the project's `docs/`, starting with its map in `docs/README.md`. It holds the project's domain and decisions. Shared conventions live in the skills.

If Engram is available, search it for earlier decisions and objections on this topic, and save new decisions there. Save every objection: a `blocker` or `should-fix` finding, an approver rejection, and a correction from the user. Record what was objected to, why, where, and how it was resolved. Update the existing entry for the same objection instead of saving a duplicate. If Engram is not available, continue without it.

If CodeGraph is available, use it to read the project's structure, symbols, call paths and impact before you use shell commands such as `grep`, `find` or `cat`. Use the shell only when CodeGraph is not available, is not indexed, or cannot answer.
