# Codex adapter

Use the generated `.codex/agents/` roles. Review roles request a read-only sandbox. Verify the effective host profile and connector capabilities; inline role instructions do not restrict tools. Project or managed workspace policy may restrict delegation, network and shared Git metadata independently.

For parallel writing, use sessions rooted in prepared worktrees with explicit paths and verified base SHAs. A spawned conversation alone is not evidence of a separate workspace. If the runtime cannot verify separate writable workspaces, use the serial fallback. To delegate plan or diagram generation, use a profile scoped to plan outputs, or pass read-only suggestions to the coordinator for writing.
